# References

Resources for deepening each group's concepts. None of these are bundled —
they're discoverable through libraries, bookstores, or online.

## Books

- **Fluent Python** (2nd ed.) — Luciano Ramalho. The definitive deep-dive into Python's object model, descriptors, metaclasses, and concurrency.
- **Python Cookbook** (3rd ed.) — David Beazley & Brian K. Jones. Recipes for files, iterators, networking, metaprogramming, and more.
- **Effective Python** (2nd ed.) — Brett Slatkin. 90 specific ways to write better Python.
- **Python Distilled** — David Beazley. A concise language reference focused on what experienced programmers need.
- **Automate the Boring Stuff with Python** (2nd ed.) — Al Sweigart. Practical automation: files, web scraping, email, GUI.
- **Python for Data Analysis** (3rd ed.) — Wes McKinney. The pandas/numpy bible by the creator of pandas.
- **Robust Python** — Patrick Viafore. Type hints, mypy, testing, and production patterns.
- **Architecture Patterns with Python** — Harry Percival & Bob Gregory. DDD, event-driven architecture, and testing strategies.

## Online Documentation

- [Python Standard Library](https://docs.python.org/3/library/) — the official reference
- [Real Python](https://realpython.com/) — in-depth tutorials
- [Python Patterns](https://python-patterns.guide/) — Brandon Rhodes's design pattern guide
- [pydoc](https://docs.python.org/3/library/pydoc.html) — `python3 -m pydoc -b` for offline browsing
